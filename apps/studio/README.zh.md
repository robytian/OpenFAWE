# OpenFAWE Studio（界面，决定 0052）

像 QBlade 那样的桌面程序：左边设定算例，中间三维视图边算边看，下面实时曲线，可以回放已存的算例、导出数据。

- **启动**：业主电脑上双击 `run_studio.bat`（用 `openfawe-accel\local\accel-venv312` 的环境，第一次会装 PySide6、pyvista、vtk）；开发时 `PYTHONPATH=src:apps/studio python -m openfawe_studio`。
- **能选的**：飞机（M600 四套数据）、涡模型（六种：VSM＋自由尾迹、升力线＋自由尾迹、UVLM、VSM 直尾迹、升力线直尾迹、VLM）、计算方式（CPU 树代码、CPU 直接求和、GPU、CPU＋GPU，没有显卡时 GPU 两项灰掉）、运动（固定在风里、圆形横风环路）、来流（风速、幂律风切变、1−cos 阵风）、时间步与步数、涡核、尾迹冻结与截断、8 个旋翼与涡环（转速、每环节点数、涡环冻结与截断）、是否画机身。
- **看的**：涡丝按环量上色（视频那种蓝色、或正负环量红蓝），涡环橙色，机翼可按附着环量上色，风（绿）和气动力（红）箭头，跟随飞机，五个视角，鼠标缩放旋转；曲线可选任一记录量（CL、CD、CY、力矩系数、气流角、旋翼力……），右边是展向附着环量。
- **存与导出**：每个算例存在 `~/OpenFAWE Studio runs/<时间>-<名字>/`（设定、逐步记录、三维帧、状态），停了或失败也留着已算的部分；导出 CSV、ParaView（`.vtp` + `.pvd`）、截图。
- **不改计算**：界面只调用库的公开函数；`tests/test_engine.py` 核对界面算的每一步记录与 `run_prescribed` 逐位相同（7 项，云端过）。机身、短舱只画不算；运动是给定的（不是自由飞行），没有系绳和重力。
