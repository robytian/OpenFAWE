Conventions of the source (checked in `analysis/aero/airfoil.py`): angles in radians; `lift_coeffs[i][j]` is flap row i,
alpha column j; lookups are bilinear in (flap, alpha) and clamp outside the table; `GetCoeffs` wraps the angle to
[−pi, pi). Stall angles used by the hover model (`hover_model.py` `GetParams`): main wing [1, 16] deg, pylons and
tails [−10, 10] deg; blend width 0.1 rad to the NACA 0012 data on a 400-point grid over ±pi. Several table entries carry
`converged: false` from XFOIL (oref 3, ref 2, f8 2, mp6d 3, rj8 3 at zero flap); they are used as the source uses them.
