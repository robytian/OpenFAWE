# Run commands

Every run of the crosswind part of the paper as it was given to the job runner of the two computers
(node 1: CPU tree code; node 2: GPU tree code, `--backend cuda_tree`). The runner called
`python SCRIPT RUN_FOLDER ARGUMENTS`; the table writes that call from the repository root, with the
output in `local/runs/` (ignored by Git). A name appears more than once when a job was queued again or
moved between the two computers; the settings actually used by a run are those recorded in its
`checks.json` and `history.json` (`settings`, including `git_commit`, `backend` and the SHA-256 of the
script and of every input file).

The GPU backend needs an NVIDIA GPU with a CUDA driver for Numba; without one, use `--backend tree`
(CPU tree code), which is the default.
