# Citing OpenFAWE

Please cite the paper:

```bibtex
@misc{Tian2026OpenFAWE,
  author        = {Tian, Yinong and Wang, Shan},
  title         = {Free-vortex-wake dynamics of airborne wind energy kites in crosswind flight},
  year          = {2026},
  eprint        = {2610.37313},
  archivePrefix = {arXiv},
  doi           = {10.48550/arXiv.2610.37313}
}
```

The software itself is described in
[`CITATION.cff`](https://github.com/robytian/OpenFAWE/blob/main/CITATION.cff) (on GitHub: *Cite this repository*).
